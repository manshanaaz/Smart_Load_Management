 Smart Load Management System

 Overview
 
This project is a MATLAB-based Smart Load Management System that monitors the total power consumption of household appliances. If the total load exceeds 2000 W, the program prompts the user to switch off an appliance to reduce the load.

Features
- Calculates total electrical load.
- Detects overload conditions.
- Allows users to switch off appliances.
- Updates total load dynamically.

 Technologies Used
- MATLAB

 How to Run
1. Open `smart_load_management.m` in MATLAB.
2. Run the script.
3. Enter the power values of the appliances.
4. Follow the prompts to manage the load.
